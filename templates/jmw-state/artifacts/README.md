# JMW Artifacts

Evidence produced by JMW agents for this project. See `.jmw/orchestration/ARTIFACTS.md` for the full rules.

| Folder | What goes here |
|---|---|
| `screenshots/` | PNG screenshots from QA, design review, game QA |
| `videos/` | Screen recordings of a flow or gameplay (not committed by default) |
| `qa-reports/` | Finished JMW-REVIEW reports and owner-review packets |
| `evidence/` | Command output, test summaries, checklists filled in |
| `logs/` | Raw logs (not committed by default) |

File names: `YYYY-MM-DD_<task-id>_<short-what>.<ext>`, for example `2026-10-13_T-004_checkout-390px.png`.

Never capture secrets, passwords, private tabs, customer personal data, full bank/tax numbers, or unrelated windows.
