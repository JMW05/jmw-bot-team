# Open Issues

One block per issue. The Project Manager keeps these current. Closed issues (`verified`, `wont-fix`) stay here for history.

How an issue moves:
`open` → `in-progress` → `fixed-unverified` (builder is done) → `verified` (a *different* agent or person confirmed it).
Anything waiting on a person is `needs-human`. Anything stuck on something else is `blocked`.
