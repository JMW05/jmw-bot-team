# Accessibility Checklist

- [ ] page has meaningful title
- [ ] heading hierarchy is logical
- [ ] images have appropriate alt treatment
- [ ] form controls have labels
- [ ] keyboard navigation works for interactive UI
- [ ] visible focus is preserved
- [ ] links/buttons have understandable names
- [ ] color is not the only carrier of meaning
- [ ] text/background contrast is reasonable
- [ ] dialogs/menus can be opened and closed accessibly
- [ ] reduced-motion behavior exists for significant motion
- [ ] errors are conveyed in text, not color alone
