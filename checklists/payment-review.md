# Payment Review Checklist

- [ ] payee/vendor identified
- [ ] amount identified
- [ ] purpose documented
- [ ] invoice/request attached
- [ ] human approval evidence present where required
- [ ] project/funding source identified
- [ ] GL/class/project coding reviewed
- [ ] duplicate indicators checked
- [ ] W-9 status considered
- [ ] 1099 tracking considered
- [ ] budget/support issue identified
- [ ] bank information not unnecessarily reproduced
- [ ] status is review status, not AI approval
