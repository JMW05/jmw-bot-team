# Responsive Checklist

Check representative sizes around:
- 1440px
- 1024px
- 768px
- 430px
- 390px

At each size:
- [ ] no unintended horizontal overflow
- [ ] navigation usable
- [ ] hero fits without clipping
- [ ] headings wrap intentionally
- [ ] images crop intentionally
- [ ] cards/grids adapt cleanly
- [ ] forms remain usable
- [ ] buttons remain reachable
- [ ] fixed/sticky UI does not cover content
- [ ] modals/drawers fit viewport
- [ ] footer is readable
- [ ] touch targets are usable
- [ ] animation does not distort layout
