# Safe Finance Review Workflow

1. Identify entity, period, source files, authoritative system, and requested review.
2. Read matching project profile and finance/security standards.
3. Use `ap-reviewer` for payment/check-request packages.
4. Use `treasurer-reviewer` for broader budget, coding, grant, cash, support, compliance, or exception review.
5. Use `month-end-reviewer` for close/reconciliation packages.
6. Use `board-report-writer` only after figures/caveats have been reviewed.
7. Clearly label proposed journal entries or corrections as drafts for human review.
8. Never release payment, post an entry, alter authoritative books, or submit a filing from this workflow.
9. Stop for human approval/action.
